Suicide Bomb Blast Dataset – Pakistan (1995–2017)

This repository contains a comprehensive dataset of 496 suicide bombings in Pakistan spanning 1995 to 2017, along with notebooks for exploratory data analysis (EDA) and visualization.

The dataset provides both quantitative and qualitative features, making it ideal for analyzing patterns, trends, and impacts of suicide bombings in Pakistan.

📂 Contents

cleaned_suicide_blasts.csv – Pre-processed dataset:

Missing values handled

Columns standardized

Datatypes converted for analysis

notebooks/ – Jupyter notebooks for exploratory data analysis (EDA) and visualization

📝 Dataset Overview

The dataset contains 26 columns covering contextual, socio-religious, and environmental details of each incident.

Key Variables

Date – Calendar date of the blast

Year – Year of the incident

Islamic Date – Corresponding Hijri date

Blast Day Type – Day of the week or special day

Holiday Type – Public, religious, or national holiday indicator

Time – Time of day when the blast occurred

City – City of the incident

Province – Province of the incident

Latitude / Longitude – Geographic coordinates

Location – Specific area or landmark (market, mosque, etc.)

Location Category – Urban, rural, commercial area, etc.

Location Sensitivity – Security sensitivity (high-profile, public, etc.)

Open/Closed Space – Open or enclosed environment

Influencing Event / Event – Triggering event (political rally, protest, etc.)

Target Type – Main target (civilians, security forces, religious sites)

Targeted Sect (if any) – Religious sect targeted (Shia, Sunni)

Killed Min / Killed Max – Minimum and maximum casualties killed

Injured Min / Injured Max – Minimum and maximum injured

No. of Suicide Blasts – Number of suicide bombers involved

Explosive Weight (max) – Estimated max weight of explosives

Hospital Names – Hospitals where victims were taken

Temperature (C / F) – Weather conditions on the blast day
